# Kotoba — Dicionário Japonês Português BR (V7)

Aplicativo web com layout responsivo profissional, tema claro/escuro, pesquisa, cadastro e edição de palavras, favoritos, flashcards, áudio por síntese de voz japonesa e backup JSON.

## Publicação com GitHub Pages

Abra **Settings → Pages** no GitHub e configure **Deploy from a branch**, branch **main**, pasta **/(root)**. Aguarde a publicação. O endereço será https://otaviofalcao208-cyber.github.io/otaviofalcao208-cyber-dicionario-japones-br/ .

## Dados e segurança

As palavras são armazenadas apenas no localStorage do navegador. Faça backups JSON regularmente. A sincronização com Supabase **não está ativada**. Nenhuma chave privada deve ser publicada neste repositório. A leitura em voz alta depende das vozes instaladas no dispositivo. O site é uma versão web/PWA; **não contém APK compilado**.

## Teste

Abra index.html no navegador ou use o GitHub Pages para testar HTTPS e service worker.
